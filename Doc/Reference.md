## System Structure

### Components

| Component | Path | Stack | Role |
|-----------|------|-------|------|
| Client app | `syncinary/` | Flutter / Dart (SDK `^3.11.0`, Flutter 3.47.2) | All UI: auth, groups, schedule, expenses, flights, hotels, preferences |
| Backend proxy | `proxy/` | Node 22, Express 4, CommonJS | Holds API keys; forwards search requests to SerpApi and Google Places; LLM helper modules |
| Auth | Firebase Auth | — | Email/password sign-in, email verification |
| Database | Cloud Firestore | — | All persistent app data (see [DB Schemas](#db-schemas)) |
| Hosting | Firebase Hosting | — | Serves `syncinary/build/web` |
| Proxy hosting | Cloud Run | `syncinary-proxy`, `us-central1` | Production proxy |

### Request flow

| From | To | Transport |
|------|----|-----------|
| Flutter app | Firebase Auth / Firestore | Firebase SDK |
| Flutter app | Proxy | HTTP GET/POST to `PROXY_URL` |
| Proxy | SerpApi (`serpapi.com/search`) | HTTPS, `api_key` query param |
| Proxy | Google Places (`places.googleapis.com/v1/places:searchText`) | HTTPS, `X-Goog-Api-Key` header |
| Proxy | Gemini (`generativelanguage.googleapis.com`) | HTTPS, `x-goog-api-key` header |

## Key APIs / Interfaces

### 1. Proxy HTTP API

| Property | Value |
|----------|-------|
| Base URL | `PROXY_URL` (default `http://localhost:3000`) |
| CORS | Open (all origins) |
| Authentication | None on search routes |

#### `GET /flights`

| Param | Required | Format | Notes |
|-------|----------|--------|-------|
| `origin` | yes | IATA code | → SerpApi `departure_id` |
| `destination` | yes | IATA code | → `arrival_id` |
| `departureDate` | yes | `YYYY-MM-DD` | → `outbound_date` |
| `adults` | no | digits only | Default `1` |
| `returnDate` | no | `YYYY-MM-DD` | Present → round trip (`type=1`); absent → one way (`type=2`) |

| Status | Body |
|--------|------|
| 200 | Array: SerpApi `best_flights`, or `other_flights` if empty, or `[]`. Round-trip offers carry `departure_token` (input to `/flights/return`) |
| 400 | `{ error }` — missing required param or non-numeric `adults` |
| 500 | `{ error: "Unable to complete the search. Please try again later." }` |

#### `GET /flights/return`

| Param | Required |
|-------|----------|
| `departureToken` | yes |
| `origin`, `destination`, `departureDate`, `returnDate`, `adults` | same values as the original `/flights` call |

| Status | Body |
|--------|------|
| 200 | Array of return-leg offers |
| 400 | `{ error }` — `departureToken` missing |
| 500 | `{ error }` — upstream failure |

#### `GET /flights/booking`

| Param | Required |
|-------|----------|
| `bookingToken` | yes |
| `origin`, `destination`, `departureDate`, `adults`, `returnDate?` | same values as the original search |

| Status | Body |
|--------|------|
| 200 | SerpApi `booking_options` array (or `[]`); each option has a plain `url` or a `booking_request` (`url` + `post_data`, needs POST) |
| 400 | `{ error }` — `bookingToken` missing |
| 500 | `{ error }` — upstream failure |

#### `GET /hotels`

| Param | Required | Notes |
|-------|----------|-------|
| `location` | yes | Free text → SerpApi `q` |
| `checkInDate` | yes | `YYYY-MM-DD` |
| `checkOutDate` | yes | `YYYY-MM-DD` |
| `adults` | no | Default `1` |

| Property | Value |
|----------|-------|
| SerpApi engine | `google_hotels` |
| Currency | `USD` (fixed) |

| Status | Body |
|--------|------|
| 200 | SerpApi `properties` array (or `[]`) |
| 400 | `{ error }` — missing required param |
| 500 | `{ error }` — upstream failure |

#### `GET /airports`

| Param | Required | Notes |
|-------|----------|-------|
| `q` | yes | 2–120 chars, trimmed |

| Case | Status | Body |
|------|--------|------|
| `q` matches a catalog IATA code exactly | 200 | `{ airports: [{ code, name, address }], source: "OurAirports" }` |
| Otherwise, Places lookup succeeds | 200 | `{ airports: [...], source: "Google Maps" }` |
| `q` length out of range | 400 | `{ error }` |
| `GOOGLE_MAPS_API_KEY` unset | 503 | `{ error }` |
| Places call fails | 502 | `{ error }` |

| Property | Value |
|----------|-------|
| Places result kept when | Exactly one catalog airport within 5 km **and** (names share words **or** Places name contains its IATA code) |
| Response header | `Cache-Control: no-store` |

#### `RecommendationService` contract

| Item | Value |
|------|-------|
| Route | `POST {PROXY_URL}/recommendations` — **not implemented** in the proxy |
| Header | `Authorization: Bearer <Firebase ID token>` |
| Request body | `{ groupId, search: { destination, startDate, query }, travelResults: [...] }` (≤ 15 results) |
| Expected success body | `{ ok: true, data }`, `data` matching [`RECOMMENDATION_OUTPUT_SCHEMA`](#recommendation_output_schema) |
| Expected failure body | `{ ok: false, error, message }`, `error` from [Error Codes](#error-codes) |
| Network error / timeout | `unreachable` |
| Non-JSON or wrong-shape reply (incl. current 404) | `malformed_response` |

#### `GroupPreferencesSummary` — `models/group_preferences_summary.dart`

| Rule | Value |
|------|-------|
| Produced by | `GroupPreferencesService.watchSummary(groupId)` |
| Minimum responses before a field is shown | 3 (`minimumResponses`) |
| Amount fields | Running mean of valid non-negative numbers |
| Choice fields | Count per option; values outside `options` ignored |
| Access check | Verified email + uid in both `members` and `memberIds`; else `GroupPreferencesAccessException` |

## Error Codes

### Recommendation pipeline (`RecommendationError` in Dart mirrors these)

| Code | Source | Meaning |
|------|--------|---------|
| `invalid_input` | `llmDataFilter.js`, `recommendationPrompt.js`, `geminiClient.js` | Malformed arguments |
| `unknown_group` | `llmDataFilter.js` | `groupId` not in data bundle |
| `not_a_member` | `llmDataFilter.js` | Requester not in group |
| `payload_too_large` | `llmDataFilter.js` | Sanitized payload > 20,000 bytes |
| `empty_payload` | `recommendationPrompt.js` | No usable sections |
| `invalid_json` | `parseRecommendationResponse` | Model reply not JSON |
| `schema_mismatch` | `parseRecommendationResponse` | Reply violates `RECOMMENDATION_OUTPUT_SCHEMA` |
| `missing_api_key` | `geminiClient.js` | `GEMINI_API_KEY` unset |
| `timeout` | `geminiClient.js` | Exceeded `GEMINI_TIMEOUT_MS` |
| `rate_limited` | `geminiClient.js` | Gemini 429 |
| `upstream_error` | `geminiClient.js` | Gemini non-2xx |
| `network_error` | `geminiClient.js` | Fetch failed |
| `invalid_response` | `geminiClient.js` | Gemini body not JSON, or no usable candidate text (incl. blocked) |
| `unreachable` | `RecommendationService` (Dart only) | Request threw (network error or timeout) |
| `malformed_response` | `RecommendationService` (Dart only) | Reply not JSON, or missing/wrong-shaped `data` |

### Proxy HTTP status codes

| Status | Routes | Cause |
|--------|--------|-------|
| 400 | all | Missing/invalid query param |
| 500 | `/flights*`, `/hotels` | SerpApi call or JSON parse failed |
| 502 | `/airports` | Google Places call failed |
| 503 | `/airports` | `GOOGLE_MAPS_API_KEY` not configured |

## LLM Recommendation Pipeline

### Stages

| # | Module | Function | Input → Output |
|---|--------|----------|----------------|
| 1 | `llmDataFilter.js` | `buildRecommendationPayload(requestContext, rawData)` | raw bundle → `{ allowed: true, payload }` \| `{ allowed: false, reason }` |
| 2 | `recommendationPrompt.js` | `buildRecommendationPrompt(payload, options?)` | payload → `{ ok: true, prompt }` \| `{ ok: false, error, message }` |
| 3 | `geminiClient.js` | `createGeminiClient().generateRecommendation({ payload, prompt })` | → `{ ok: true, text, latencyMs, usage }` \| `{ ok: false, error, message }` |
| 4 | `recommendationPrompt.js` | `parseRecommendationResponse(text)` | → `{ ok: true, data }` \| `{ ok: false, error }` |

| Property | Value |
|----------|-------|
| Error handling | No stage throws; all return a result object |
| Wired to a proxy route | No |

### Input limits (`llmDataFilter.js`)

| Constant | Value |
|----------|-------|
| `MAX_STRING_LENGTH` | 300 (strings truncated) |
| `MAX_ARRAY_ITEMS` | 15 (arrays truncated) |
| `MAX_MEMBERS` | 25 |
| `MAX_PAYLOAD_BYTES` | 20,000 (over → `payload_too_large`) |
